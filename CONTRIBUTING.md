# Contributing

Thanks for helping improve reviewer.

## Development

```sh
python3 -m pip install --upgrade pip build
python3 -m unittest discover -s tests -v
python3 -m build
```

The project targets Python 3.8+ and uses only the standard library at runtime. Keep it that way unless a change is discussed first.

## Rules for changes

- Keep output plain when piped: no emoji or animation. Bold headers, colour accents and status markers are allowed only on a TTY and must stay gated by `NO_COLOR`, `REVIEWER_NO_BANNER` and `--no-banner`.
- Never put an API key in argv, logs, tracebacks, generated files or git.
- Generated files must keep the `Generated by reviewer` marker, SPDX identifier and copyright line.
- Add or update tests for behaviour changes.
- Do not change the pinned API default URLs without documenting verification in the README providers table.

## Pull requests

1. Fork and create a branch.
2. Make a focused change.
3. Run the tests and build.
4. Open a pull request describing what changed and how you verified it.
